# Algebra

Algebra is a branch of mathematics that uses symbols, variables, numbers, and mathematical operations to represent relationships and solve problems.

## Introduction

Arithmetic mainly deals with known numerical quantities, while algebra allows us to work with unknown quantities.

For example:

**x + 5 = 10**

Here, **x** represents an unknown value.

Algebra provides a general way of describing mathematical relationships and solving problems.

---

## Variables

A variable is a symbol that represents an unknown or changing quantity.

Common variables include:

- x
- y
- a
- b
- n

For example:

**x + 4 = 9**

The value of **x** can be determined by solving the equation.

Therefore:

**x = 5**

---

## Constants

A constant is a value that does not change within a particular mathematical expression.

For example:

**3x + 7**

Here:

- **x** is the variable.
- **3** is the coefficient.
- **7** is the constant.

---

## Algebraic Expressions

An algebraic expression combines numbers, variables, and mathematical operations.

Examples include:

**2x + 5**

**3a - 7**

**x² + 4x + 4**

Expressions do not necessarily contain an equality sign.

---

## Equations

An equation states that two mathematical expressions are equal.

For example:

**2x + 4 = 10**

To solve it:

**2x = 10 - 4**

**2x = 6**

Therefore:

**x = 3**

---

## Linear Equations

A linear equation is an equation in which the highest power of the variable is one.

For example:

**2x + 5 = 15**

Solving:

**2x = 10**

Therefore:

**x = 5**

Linear equations are widely used for representing relationships between quantities.

---

## Quadratic Equations

A quadratic equation contains a variable raised to the second power.

The general form is:

**ax² + bx + c = 0**

where:

- **a** is not zero.
- **b** and **c** are constants.
- **x** is the variable.

For example:

**x² + 5x + 6 = 0**

Quadratic equations can be solved using methods such as factorization and other algebraic techniques.

---

## Algebraic Operations

Algebra uses many of the same fundamental operations as arithmetic.

These include:

- Addition
- Subtraction
- Multiplication
- Division
- Exponentiation

For example:

**2x + 3x = 5x**

and:

**4x × 2 = 8x**

---

## Algebraic Identities

An algebraic identity is an equality that remains true for all valid values of its variables.

Some common identities are:

**(a + b)² = a² + 2ab + b²**

**(a - b)² = a² - 2ab + b²**

**(a + b)(a - b) = a² - b²**

These identities are useful for simplifying expressions and solving mathematical problems.

## Algebra and Problem Solving

One of the major strengths of algebra is that it allows a general problem to be represented symbolically.

For example, instead of saying:

> A number increased by 10 gives 25.

We can represent the problem as:

**x + 10 = 25**

Therefore:

**x = 15**

This symbolic representation makes it easier to solve and generalize mathematical problems.
